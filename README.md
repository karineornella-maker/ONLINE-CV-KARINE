## 🚀 Comment Lancer le Site Localement

### Méthode 1 : Lancement en 1 Clic (Ultra Rapide)
Double-cliquez simplement sur **`lancer.bat`** (dans l'explorateur Windows) :
- Le serveur local démarre automatiquement.
- Votre navigateur par défaut s'ouvre directement sur le CV (`http://localhost:3000`).

### Méthode 2 : Ouverture Directe sans Serveur
Double-cliquez directement sur **`index.html`** (ou sur **`lancer-direct.bat`**) pour l'ouvrir immédiatement dans votre navigateur habituel.

### Méthode 3 : Lancement via Terminal PowerShell
Dans un terminal dans ce dossier, exécutez :
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```
*Le navigateur s'ouvre automatiquement dès le démarrage du serveur.*

## 🌐 Déploiement en Ligne Gratuit (en 2 minutes)

- **Option A (GitHub Pages)** :
  1. Créez un dépôt sur GitHub et poussez les fichiers (`index.html`, `style.css`, `app.js`, `assets/`).
  2. Dans les paramètres du dépôt (*Settings > Pages*), sélectionnez la branche `main` et enregistrez.
  3. Votre CV sera en ligne avec votre adresse : `https://<votre-compte>.github.io/<nom-du-repo>/`.

- **Option B (Vercel ou Netlify)** :
  1. Connectez-vous sur [vercel.com](https://vercel.com) ou [netlify.com](https://netlify.com).
  2. Glissez-déposez simplement le dossier de votre projet.
  3. Votre site est déployé instantanément avec un nom de domaine gratuit sécurisé HTTPS.
